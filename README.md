# Ninho Finance

Projeto organizado como um monorepo simples.

## Estrutura

- `backend/`: aplicação Spring Boot
- `frontend/`: reservado para o frontend
- `docs/`: reservado para a documentação

## Backend

No Windows:

```powershell
cd backend
.\mvnw.cmd spring-boot:run
```

Para executar os testes:

```powershell
cd backend
.\mvnw.cmd test
```
